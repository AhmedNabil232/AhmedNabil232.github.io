Hesabate

Offline-first · Migration

An accounting and field-sales app for sales delegates who spend their day out of signal range. I led its migration from native Android to Flutter and shipped it to both stores.

The real work was the data layer. The app carries a 64-table local database — 11 document types, multi-store inventory, tiered price lists, serial and warranty tracking. I rebuilt it on sqflite and hand-wrote the migration path across eight schema versions so that no existing user lost data on upgrade.

Then made it fast on cheap hardware: WAL journaling, bulk inserts chunked so the UI thread keeps breathing, and catalogue parsing moved off the main isolate. It also drives thermal printers and barcode scanners, and runs in Arabic and English.

Stack
Flutter · Dart · sqflite · Hive · BLoC / Cubit · GetX · Clean Architecture
Data
64 tables · ~949 columns · 22 indexes · schema v21 → v28, zero data loss
